How to Play

The rules of the pipeline

  1. Each team is one sequential AI workflow. Each player is one agent.
  2. An agent sees only its own instructions and the output of the agent before it.
  3. Nobody can skip ahead. The Searcher cannot start until the Planner submits.
  4. The whole team shares one timer. When it expires, every input locks.
  5. Each stage is worth 25 points. Wrong selections cost you. Speed earns a bonus.
